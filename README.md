# WARRIOR FROM OUTER SPACE
**Console:** Python Phantasy System (8-Bit CRT Arcade Engine)  
**Estúdio:** CAMPGAMES ARTS  

## Sobre o Jogo
Ano 3084. A Terra não passa de um fantasma radioativo. No comando do caça pesado **Valkyrie-X8**, você é **Kael "Ferrugem" Vance**, o último piloto da divisão *Star-Hounds*, defendendo as 30 colônias humanas contra a armada biomecânica de **VORTEX-9**.

Projeto 100% procedural em Python + Pygame:
- **Zero Assets Externos:** Todos os sprites, texturas de ferrugem, fontes e efeitos sonoros são gerados via código em tempo de execução.
- **Filtro CRT em Tempo Real:** Scanlines, vinheta de tubo e sangramento RGB.

## Como Executar
```bash
pip install pygame
python main.py
```
